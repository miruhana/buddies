# Buddies（バディーズ）

スマホが苦手な方のための、やさしいデジタルサポートアプリです。

- スマホの基本的な使い方
- LINEの使い方
- サブスクリプションの使い方・解約のしかた
- テレビでスマホの動画を見る方法
- あやしい連絡のチェック、困ったときのQ&A

## 使い方

下のリンクをスマホやパソコンで開くだけで使えます。登録やインストールは必要ありません。

**https://miruhana.github.io/buddies/**

> スマホのホーム画面に追加すると、アプリのように開けます。
> （iPhone：共有ボタン →「ホーム画面に追加」／Android：メニュー →「ホーム画面に追加」）

## AIに相談する機能

「話しかける」「写真で聞く」は、Cloudflare Workers AI の無料枠（AIモデル：Gemma 4）を使っています。利用者も運営者も費用はかかりません。

- 1日に使える回数には上限があります（全員の合計で約100〜150回、1回線あたり1日30回まで）。上限に達すると「また明日どうぞ」と表示されます。
- 送った内容や写真は、AIの学習には使われません。
- 中継プログラムは `worker/` フォルダにあります。更新するときは `worker` フォルダで `npx wrangler deploy` を実行します。
- Claude上で開いた場合は、Claudeが答えます。
