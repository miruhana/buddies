# Buddies（バディーズ）

スマホが苦手な方のための、やさしいデジタルサポートアプリです。

- スマホの基本的な使い方
- LINEの使い方
- サブスクリプションの使い方・解約のしかた
- テレビでスマホの動画を見る方法
- あやしい連絡のチェック、困ったときのQ&A

## 使い方

下のリンクをスマホやパソコンで開くだけで使えます。登録やインストールは必要ありません。

**https://miruhana.github.io/buddies/**

> スマホのホーム画面に追加すると、アプリのように開けます。
> （iPhone：共有ボタン →「ホーム画面に追加」／Android：メニュー →「ホーム画面に追加」）

## 補足

「話しかける」「写真で聞く」のAI相談機能は、Claude上で開いたときだけ使えます。
このリンクでは、アプリ内の案内から答えを探す形で動きます。
